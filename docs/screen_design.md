# 画面設計（現行実装）

## HomeScreen

- 役割：アプリの起点。当日の集計を表示し、通常モードと配達中モードを切り替える。
- 表示項目：ロゴ、挨拶、今日の利益、今日の売上、今日の件数、オンライン時間。配達中は「配達中です」、目標件数、天気を追加表示。
- ボタン：通常時「配達開始」、配達中「配達終了」。下部ナビゲーション（ホーム、履歴、設定）。
- 入力項目：なし。
- 遷移先：配達開始 → StartDistanceScreen、配達終了 → FinishInputScreen。下部ナビゲーションの履歴・設定は選択状態を変更するが、現状は画面内容の切り替えが未接続。

## StartDistanceScreen

- 役割：配達開始時の開始走行距離を確認する。
- 表示項目：前回終了走行距離（現状 106,620km）、説明文、挨拶ヘッダー。
- ボタン：「変更する」（現状未接続）、「次へ」。戻るボタンあり。
- 入力項目：本来は開始距離。現状は入力 UI なし。
- 遷移先：次へ → TargetCountScreen。戻る → HomeScreen。

## TargetCountScreen

- 役割：当日の目標配達件数を確認する。
- 表示項目：目標件数（初期値 20件）、説明文、挨拶ヘッダー。
- ボタン：「変更する」（現状未接続）、「次へ」。戻るボタンあり。
- 入力項目：本来は目標件数。現状は入力 UI なし。
- 遷移先：次へ → WeatherScreen。戻る → StartDistanceScreen。

## WeatherScreen

- 役割：当日の天気を選択し、配達セッションを開始する。
- 表示項目：晴れ、曇り、雨、選択状態チェック、挨拶ヘッダー。
- ボタン：「配達を開始する」。戻るボタンあり。
- 入力項目：天気（選択式、初期値は晴れ）。
- 遷移先：配達を開始する → HomeScreen（配達中モード）。戻る → TargetCountScreen。

## FinishInputScreen

- 役割：配達終了時の実績値を入力する。
- 表示項目：挨拶ヘッダー、入力フォーム。
- ボタン：「保存する」。戻るボタンあり。
- 入力項目：オンライン時間（例 8:00）、今日の売上（円）、配達件数、走行距離（km）。
- 入力検証：空欄は保存不可。売上・件数・走行距離は整数として解釈できない場合に保存不可。保存中の二重実行を抑止する。
- 遷移先：保存成功 → HomeScreen（通常モード）。戻る／保存失敗 → FinishInputScreen に留まる。
