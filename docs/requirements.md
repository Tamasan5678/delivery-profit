# 要件定義（現行実装）

## アプリ概要

Delivery Profit V2 は、フードデリバリー業務の売上、配達件数、走行距離、オンライン時間を記録し、日々の利益確認を支援する Flutter 製 Android アプリである。

## 対応画面方向

Delivery Profitはスマートフォンでの片手操作性を重視するため、縦画面（Portrait）のみ対応とする。横画面（Landscape）はサポート対象外とし、UI設計・テスト・品質保証も縦画面のみを対象とする。

品質保証対象はPortraitUpのスマートフォンUIとする。最小対応幅360dp、標準確認幅411dp、大型確認幅480dpで、RenderFlex overflow、主要文字の欠落、主要ボタンへの到達不能がないことを必須とする。文字サイズ・表示サイズ拡大時は、必要な画面を縦スクロールして主要操作へ到達できることを要件とする。タブレット専用UIは対象外とする。

## 目的

- 配達開始から終了までの状況を簡単に記録する。
- 当日の売上・件数・オンライン時間などを HomeScreen で確認できるようにする。
- 将来的に履歴分析、計算、永続化へ拡張できる構成にする。

## 実装済み機能

- HomeScreen の通常モード表示（挨拶、ロゴ、今日の利益・売上・件数・オンライン時間）。
- HomeScreen の配達中モード切替。
- 配達開始フロー（開始距離画面、目標件数画面、天気選択画面）。
- 天気（晴れ・曇り・雨）の選択と DeliverySession への保持。
- 配達中モードでの目標件数、天気、配達終了ボタンの表示。
- 配達終了フロー（FinishInputScreen）。
- オンライン時間、売上、配達件数、走行距離の入力。
- 未入力チェックおよび数値入力チェック（SnackBar 表示）。
- 完了後の HomeScreen への結果反映（売上、件数、オンライン時間）。
- 保存完了直後の本日の配達結果画面表示と、同画面から HomeScreen 通常モードへの復帰。
- 日別の利益、時給、平均利益／件、平均走行距離／件、平均配達時間／件、平均消費ガソリン／件の計算表示。
- SettingsScreen での平均燃費・ガソリン単価のスクロール入力と SharedPreferences への保存・復元。
- 保存した平均燃費とガソリン単価を使用したガソリン代・利益計算。
- 配達終了時の実績、設定値、計算結果を1セッション1行でSQLiteへ保存。
- Repositoryによる1件取得、全件取得、期間指定取得、削除API。
- 本日・今週・今月のSQLite実績復元と、同一期間に含まれる全セッションの合算表示。
- HomeScreenから履歴画面へ遷移し、終了日時の新しい順で実績一覧を表示。
- 履歴カードから保存済みDeliveryRecordの詳細を表示し、確認後に1件削除できる。
- 配達開始確定時にDeliverySessionをSharedPreferencesへ一時保存し、アプリ起動時に配達中状態を復元する。
- 配達開始時に外部依存を使わない十分一意なsessionIdを生成し、DeliverySession、一時データ、DeliveryRecord、SQLiteで一貫して保持する。
- SQLite version 2のmigrationで既存履歴へsessionIdを補完し、UNIQUE INDEXで同一セッションの重複保存を防止する。
- 起動時に一時データのsessionIdがSQLite保存済みなら配達中へ復元せず、一時データの無効化を再試行する。
- 未保存の計算設定は既定値10.0km/L、170円/Lを正式値として使用する。
- 計算設定は単一JSONとして1回で保存し、旧2キーはJSON保存成功後に移行・削除する。
- ガソリン代を整数へ丸めてから利益を`売上 - 保存ガソリン代`で確定し、結果・履歴・集計は保存済み整数値を使用する。
- 配達実績はModel、Repository、SQLite version 3 CHECK制約の3段階で検証し、不正値と利益不整合を保存しない。
- 前回終了距離を「開始時の車両総走行距離 + 当該配達の走行距離」としてSQLite保存成功後に保持し、次回の開始距離初期値に使用する。履歴削除では巻き戻さない。
- 日・週・月集計はリクエスト世代を照合し、最後に選択した期間以外の非同期結果を表示へ反映しない。
- 主要画面遷移、保存、削除、設定決定は処理中フラグにより高速連打時の多重実行を防止する。
- SQLite保存成功後だけ配達中一時データを無効化し、保存失敗時は保持する。
- Repositoryと配達中保存サービスを画面へ注入でき、Fakeを使うWidgetテストを実行できる。
- SQLite保存成功時のみ結果画面へ進み、失敗時は入力を維持して再試行可能。
- FinishInputScreen から戻った場合の配達中状態維持。
- 共通ボタン、情報カード、挨拶ヘッダー、テーマカラー等の共通ウィジェット。
- SharedPreferences 用の PreferencesService（開始・終了距離、目標件数、目標売上の保存・取得 API）。

## 未実装機能・現状の制約

- 開始距離・目標件数画面の「変更する」操作に入力 UI がなく、現在は表示値（開始距離 106,620km、目標件数 20件）を変更できない。
- 目標件数・目標売上のPreferencesService APIは画面フローへ未接続。
- CSV 出力、Google Drive バックアップ、グラフ、データ分析は未実装。

## 今後の予定

3. 利益・コスト・効率指標の計算を追加する。
4. 設定画面、CSV 出力、バックアップ、グラフ表示を段階的に追加する。
