# 要件定義（現行実装）

## アプリ概要

Delivery Profit V2 は、フードデリバリー業務の売上、配達件数、走行距離、オンライン時間を記録し、日々の利益確認を支援する Flutter 製 Android アプリである。

## 目的

- 配達開始から終了までの状況を簡単に記録する。
- 当日の売上・件数・オンライン時間などを HomeScreen で確認できるようにする。
- 将来的に履歴分析、計算、永続化へ拡張できる構成にする。

## 実装済み機能

- HomeScreen の通常モード表示（挨拶、ロゴ、今日の利益・売上・件数・オンライン時間）。
- HomeScreen の配達中モード切替。
- 配達開始フロー（開始距離画面、目標件数画面、天気選択画面）。
- 天気（晴れ・曇り・雨）の選択と DeliverySession への保持。
- 配達中モードでの目標件数、天気、配達終了ボタンの表示。
- 配達終了フロー（FinishInputScreen）。
- オンライン時間、売上、配達件数、走行距離の入力。
- 未入力チェックおよび数値入力チェック（SnackBar 表示）。
- 完了後の HomeScreen への結果反映（売上、件数、オンライン時間）。
- FinishInputScreen から戻った場合の配達中状態維持。
- 共通ボタン、情報カード、挨拶ヘッダー、テーマカラー等の共通ウィジェット。
- SharedPreferences 用の PreferencesService（開始・終了距離、目標件数、目標売上の保存・取得 API）。

## 未実装機能・現状の制約

- 開始距離・目標件数画面の「変更する」操作に入力 UI がなく、現在は表示値（開始距離 106,620km、目標件数 20件）を変更できない。
- PreferencesService は存在するが、画面フローとの接続および実績値の永続化は未完了。
- SQLite による配達履歴保存は未実装。
- 履歴画面・設定画面はファイルとして存在するが、HomeScreen のナビゲーション先として内容を切り替える実装は未完了。
- 利益計算、平均単価、1件あたり走行距離などの計算表示は未完了。
- CSV 出力、Google Drive バックアップ、グラフ、データ分析は未実装。
- セッションの復元、アプリ再起動後の配達中状態復元は未実装。

## 今後の予定

1. 開始距離・目標件数の編集 UI と入力値検証を実装する。
2. SQLite に配達セッション／完了実績を保存し、履歴画面を接続する。
3. 利益・コスト・効率指標の計算を追加する。
4. 設定画面、CSV 出力、バックアップ、グラフ表示を段階的に追加する。
