# Delivery Profit 開発ロードマップ

## この文書の目的

開発対象をリリース段階ごとに分け、「今すぐ実装するもの」と「将来検討するアイデア」を明確にする。今後の実装では、原則として上位の段階を完成させてから次の段階へ進む。

## MVP（最優先）

初回リリースに必要な機能。未完了項目は、ほかのバージョンの機能より優先する。

### 実装済み

- HomeScreen（通常モード／配達中モード）
- 配達開始フロー
- 配達終了と実績入力
- 本日の配達結果画面
- 利益、平均利益／件、平均走行距離／件、平均配達時間／件、平均消費ガソリン／件の計算
- HomeScreenの日別集計表示

### リリースまでに実装

- 平均燃費とガソリン単価を入力・保存できる設定画面
- SQLiteによる配達実績の保存
- 保存データを使用した日別集計
- 収支履歴画面の基本表示
- 開始距離入力と前回終了距離の引き継ぎ
- 入力値、計算結果、保存・復元処理の動作確認

## Version 1.1

初回リリース後、集計と履歴確認を充実させる機能。

- 週別集計
- 月別集計
- 週別・月別グラフ表示
- 収支履歴の詳細表示
- 設定画面の操作性改善
- 配達セッションの復元

週別・月別の平均値は、日ごとの平均の単純平均ではなく、期間全体の合計値と配達件数から計算する。

## Version 1.5

記録が増えた利用者向けの管理・持ち出し機能。

- CSV出力
- 履歴検索
- 履歴の並び替え
- 期間や条件によるフィルター
- ローカルデータのバックアップと復元

## Version 2.0

外部サービスや複数端末を利用する高度な機能。

- クラウド同期
- 複数端末間のデータ同期
- Google Drive連携
- 配達成果の画像出力
- SNS共有

認証、同期競合、プライバシー、データ移行の設計を確定してから実装する。

## 将来アイデア

以下は実装時期未定の検討候補であり、MVPおよび各バージョンの確定要件には含めない。

### 成果画面の方向性

Delivery Profitは「数字を入力するアプリ」だけではなく、「今日の成果を見てモチベーションが上がるアプリ」を目指す。本日の配達結果画面を、利用者が最も達成感を得られる画面として育てる。

### メッセージ候補

- 利益が0円以上：「本日の配達、お疲れさまでした！」
- 目標売上達成：「目標売上達成！おめでとうございます！」
- 目標件数達成：「目標件数もクリアしました！」

文言、表示条件、利益がマイナスの場合の扱いは、実装時に別途決定する。

### 演出・記録・共有の候補

- バッジ機能
- 最高利益更新
- 連続配達記録
- 紙吹雪
- 星エフェクト
- 達成スタンプ
- SNS共有
- 画像保存

これらはアイデアのみとし、優先バージョンへ明示的に移されるまで実装しない。
