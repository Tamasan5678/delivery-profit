# Delivery Profit V2

## 概要

Delivery Profitは、フードデリバリー配達員が
毎日の利益を簡単に把握し、
効率良く稼ぐためのアプリです。

---

## 開発理念

- 入力は最小限
- 利益を最優先
- 配達データを見える化する
- 長く使えるシンプルなUI
- 将来の機能追加を考えた設計

---

## MVP（最初に完成させる機能）

### 入力

- オンライン時間
- 売上
- 配達件数
- 走行距離

### 設定

- 平均燃費
- ガソリン単価

### 出力

- 利益
- 平均利益／件
- 1件当たりの走行距離
- 1件当たりの平均配達時間
- 1件当たりの平均消費ガソリン
