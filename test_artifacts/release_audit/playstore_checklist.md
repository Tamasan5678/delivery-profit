# Google Play 公開準備チェックリスト

## ストア掲載情報

- [ ] 正式アプリ名
- [ ] 短い説明
- [ ] 詳細な説明
- [ ] 「あなたは、この配達の利益、分かりますか？」を核に、売上ではなく利益を把握できる価値を説明
- [ ] アプリカテゴリ・タグ
- [ ] 問い合わせメールアドレス
- [ ] ウェブサイト（用意する場合）
- [ ] 著作権・権利表記

## グラフィック

- [ ] Google Play用512×512アプリアイコン
- [ ] Feature Graphic（1024×500、JPEGまたは24-bit PNG、alphaなし）
- [ ] スマートフォン用スクリーンショット
- [ ] Home利益、終了入力、結果、履歴、設定を含む一貫した画像セット
- [ ] 必要な対象端末のスクリーンショット
- [ ] 画像のalt text
- [ ] ストア画像と実アプリ機能・表示の一致確認

## ポリシー・申告

- [ ] 公開URLのプライバシーポリシー
- [ ] アプリ内からプライバシーポリシーへ到達可能にするか判断
- [ ] Data safetyフォーム（データ非収集の場合も申告）
- [ ] 利用規約の要否判断
- [ ] コンテンツレーティング / 年齢区分
- [ ] 対象年齢と子ども向け該当性
- [ ] 広告の有無
- [ ] アプリのアクセス権（ログイン不要であることを確認）
- [ ] 政府・金融・健康等の該当申告を確認

## 配布・審査

- [ ] 公開用Application ID確定
- [ ] Play App Signing登録
- [ ] 本番署名AABアップロード
- [ ] 内部テスト
- [ ] クローズドテスト要件の該当確認
- [ ] Pre-launch report確認
- [ ] Device catalogの対応範囲確認
- [ ] 国・地域、価格、配布対象を決定
- [ ] リリースノート
- [ ] 審査用説明とストア掲載内容が実装と一致

## 現状評価

ローカルリポジトリにはFeature Graphic、ストア説明、プライバシーポリシー、Data safety回答、年齢区分、問い合わせ先等を確認できなかった。Data safetyはデータを外部収集しない場合もPlay Consoleでの申告とプライバシーポリシーURLが必要。公開素材の公式要件は次を参照。

- Preview assets: https://support.google.com/googleplay/android-developer/answer/9866151
- Data safety: https://support.google.com/googleplay/android-developer/answer/10787469
- Target API: https://support.google.com/googleplay/android-developer/answer/11926878
