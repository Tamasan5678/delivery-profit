# Portrait画面サイズ品質ルール

## 正式対象

- 画面方向: Portraitのみ
- 許可方向: PortraitUp
- 非対応: PortraitDown、LandscapeLeft、LandscapeRight
- タブレット専用UIおよび横画面専用レイアウトは対象外
- 横画面未確認はリリース阻害事項としない

## 標準確認幅

| 区分 | 論理サイズ | 用途 |
|---|---:|---|
| 最小 | 360 x 640dp以上 | 最低品質基準、最重要 |
| 標準 | 411 x 891dp前後 | 標準スマートフォン |
| 大型 | 480 x 960dp前後 | 大型スマートフォン |

## 合格基準

- 360dpでRenderFlex overflow、BoxConstraintsエラー、主要文字の欠落がない
- 主要ボタンが画面外へ固定されず、必要な画面は縦スクロールで到達できる
- 文字サイズ拡大時も重要な利益・売上・時給と主要操作へ到達できる
- タップ領域を極端に縮小しない
- 固定幅・固定高さへ過度に依存しない
- Dialog、BottomSheet、スクロールピッカーの決定・キャンセル操作が可能
- テスト後はsurface sizeと文字倍率を必ず復元する

今後の新規画面およびUI変更は、360dp、411dp、480dpの3幅でWidgetテストまたは同等の確認を行う。
