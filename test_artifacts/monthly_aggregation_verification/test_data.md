# テストデータ定義

## 基本レコード

| 項目 | 値 |
|---|---:|
| 売上 | 10,000円 |
| 配達件数 | 20件 |
| 走行距離 | 100.0km |
| オンライン時間 | 300分 |
| ガソリン使用量 | 10.0L |
| ガソリン代 | 2,000円 |
| 利益 | 8,000円 |
| 平均燃費 | 10.0km/L |
| ガソリン単価 | 200円/L |

- 開始: 各ローカル日の09:00
- 終了: 開始から5時間後
- 保存: `DateTime(...).toUtc().millisecondsSinceEpoch`
- sessionId: 日付または連番を含む全件固有値

## シナリオ

1. 2026-08-01～08-31: 31件
2. 2026-07-31、09-01: 各1件
3. 2026-08-15 12時・18時開始: 追加2件
4. 保持シナリオ最終: 合計35件
5. 大量データ: 2025-09-01～2026-08-31、365件
6. Home Fake: 月31件、週7件

すべて監査専用の一時SQLite DBまたはメモリFake Repositoryにのみ作成した。一時DBはテスト終了時に閉じて専用一時ディレクトリから削除し、本番DBには接続していない。
